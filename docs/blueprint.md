# **App Name**: HealthCompass Navigator

## Core Features:

- AI-Powered Symptom Analysis: Chat with an AI tool to analyze user-provided symptoms and suggest relevant medical specialists. The tool will make judgements about when and if to incorporate specific details from the problem description.
- Admin Login: Secure login for administrators to access patient data visualizations.
- Registration Page: Allow new users to register providing their Name, Mobile number, Age, Gender and Location
- Data Visualization Dashboard: Display patient data, such as the number of users who contacted for neurologist and more, in a pie chart or bar chart format.
- Informational 'About' Section: Include an about section with cards which shows background details about healthcompass service.
- Animated User Interface: Subtle animations to indicate loading or the effect of user input events. Larger animations when components mount.
- Responsive Navigation Bar: Implement a responsive navbar with navigation links, admin login, and a registration/get started button.

## Style Guidelines:

- Primary color: Calm blue (#72BCD4) to evoke trust and health.
- Background color: Light, desaturated blue (#F0F8FF) to create a clean, professional feel.
- Accent color: Soft green (#8BC34A) for CTAs and highlighting key information.
- Body and headline font: 'Inter' sans-serif for a modern, neutral, readable look.
- Use clean, modern icons related to health and medical assistance.
- Maintain a clean and structured layout with clear sections for each type of content.
- Implement smooth transitions and loading animations to improve user experience.
